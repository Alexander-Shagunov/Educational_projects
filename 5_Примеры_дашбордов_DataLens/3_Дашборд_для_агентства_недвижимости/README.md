# Бизнес-контекст задачи:
Доработать существующий дашборд по требованиям заказчика. Нужно добавить новые фильтры и возможности для анализа данных, а также усовершенствовать отображение информации об объектах недвижимости.
ТЗ:
1. Добавьте фильтр по типам населённых пунктов.
2. Выведите показатель «Средняя площадь». Он даст представление о стандартных размерах квартир, пользующихся спросом на рынке.
3. Отобразите среднее количество дней продажи на одну квартиру. Эта метрика покажет уровень спроса и предложения на рынке и поможет оценить, насколько быстро в среднем продаются квартиры.
4. Создайте чарт «Топ-5 по количеству дней продажи». Сотруднику агентства важно видеть населённые пункты, где квартиры продаются быстрее всего.
5. Добавьте фильтр для детализации данных по дням, неделям, месяцам и годам.
