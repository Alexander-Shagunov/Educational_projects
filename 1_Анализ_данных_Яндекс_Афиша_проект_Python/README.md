# Бизнес-контекcт задачи
Коллеги из продуктовой команды просят провести исследовательский анализ данных, чтобы выявить инсайты об изменении пользовательских предпочтений и популярности событий осенью 2024 года, а также проверить гипотезы о разнице в поведении пользователей с мобильными и стационарными устройствами.

Весь код, описание данных, анализ, выводы и рекомендации находятся в файле Jupyter Notebook (.ipynb).
Использованные библиотеки: pandas, numpy, scipy, matplotlib, seaborn.
