# Educational projects — портфолио проектов по анализу данных

Репозиторий содержит учебные и практические проекты по анализу данных: исследовательский анализ, A/B-тестирование и проверку статистических гипотез на Python, а также BI-дашборды в Yandex DataLens.

| 1 | [Анализ данных Яндекс Афиша] | Jupyter Notebook | pandas, numpy, scipy, matplotlib, seaborn |

## Описание проектов

### 1. Анализ данных Яндекс Афиша
Исследовательский анализ данных для продуктовой команды: выявление изменений пользовательских предпочтений и популярности событий осенью 2024 года, проверка гипотез о различиях в поведении пользователей мобильных и стационарных устройств.

### 2. Исследование стартапов
Анализ исторических данных о финансировании стартапов по заказу венчурной компании — поиск закономерностей инвестирования и оценка перспектив выхода на рынок.

### 3. Разработка A/B-теста и анализ результатов
Расчёт параметров A/B-теста и анализ его результатов для приложения с «бесконечной» лентой контента (по аналогии с приложениями коротких видео) и двумя моделями монетизации (подписка / реклама). Проверяется гипотеза об эффективности нового алгоритма рекомендаций.

### 4. Статистическая проверка гипотез и A/B-анализ
Проект из двух независимых частей: (1) проверка статистическим тестом гипотезы о различиях во времени, проводимом за чтением/прослушиванием контента Яндекс Книг пользователями Санкт-Петербурга и Москвы; (2) статистический анализ результатов A/B-теста интернет-магазина товаров для здорового образа жизни.

### 5. Примеры дашбордов DataLens
Три BI-дашборда, разработанных в Yandex DataLens:
- **Аналитика Яндекс Афиши** — дашборд для отслеживания динамики бизнес-показателей, популярности мероприятий и структуры выручки по категориям событий и устройствам (данные из 5 связанных таблиц: заказы, мероприятия, площадки, города, регионы).
- **Анализ TED-конференций** — дашборд для аналитического агентства, помогающий заказчику подбирать спикеров, темы и площадки на основе опыта прошлых конференций (данные о конференциях, спикерах и выступлениях).
- **Дашборд для агентства недвижимости** — доработка существующего дашборда: новые фильтры (по типу населённого пункта, по периодам), показатели средней площади и среднего срока продажи, топ-5 населённых пунктов по скорости продаж.

## Технологии
Python (pandas, numpy, scipy, matplotlib, seaborn, statsmodels), Jupyter Notebook, SQL, Yandex DataLens.
