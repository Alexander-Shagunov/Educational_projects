# Проект Проверка гипотез и A/B-анализ

# Бизнес-контекcт задачи
В проекте есть две независмые части.
Первая часть - проверка с помощью статистического теста на Python гипотезы о том, что пользователи Яндекс Книг из Санкт‑Петербурга в среднем проводят больше времени за чтением и прослушиванием контента, чем пользователи из Москвы.
Вторая часть - с помощью статистического теста на Python анализ результатов A/B-тестирования на примере интернет-магазина, в котором продаются товары для тех, кто ведёт здоровый образ жизни.

Весь код, описание данных, анализ, выводы и рекомендации находятся в файле Jupyter Notebook (.ipynb).
Использованные библиотеки: pandas, matplotlib, seaborn, scipy, statsmodels.
