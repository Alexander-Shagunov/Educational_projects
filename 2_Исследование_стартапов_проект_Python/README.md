# Бизнес-контекcт задачи
Финансовая компания, работающая с венчурными инвестициями, хочет понять закономерности финансирования стартапов и оценить перспективы выхода на рынок с покупкой и развитием компаний.
Для этого необходимо провести исследование на исторических данных.

Весь код, описание данных, анализ, выводы и рекомендации находятся в файле Jupyter Notebook (.ipynb).
Использованные библиотеки: pandas, matplotlib, seaborn.
